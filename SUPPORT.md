# Dúvidas e suporte

Comece pelo [README](README.md), pelo [guia da linguagem](LINGUAGEM.md) ou pelo [guia da IDE](docs/ide.md). Dentro do aplicativo, o menu **Documentação** oferece exemplos copiáveis e funciona offline.

Se a dúvida continuar, use o [modelo de dúvida](https://github.com/alumia-brasil/alumia-br/issues/new/choose). Conte o que tentou fazer, compartilhe um trecho pequeno do código e inclua a mensagem de erro completa, se houver.

Para um defeito reproduzível, use o modelo de erro. Para uma ideia, descreva o que ela ajudaria alguém a aprender. O projeto não oferece atendimento comercial nem prazo garantido de resposta.

Não publique dados pessoais, senhas ou tokens. Para uma possível vulnerabilidade, siga [SECURITY.md](SECURITY.md).
