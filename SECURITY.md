# Relatar um problema de segurança

Consulte a [aba Security da Alumia](https://github.com/alumia-brasil/alumia-br/security). Se o formulário **Report a vulnerability** estiver disponível, envie o relato por ele. Caso contrário, abra uma issue pedindo um contato privado e aguarde a resposta da manutenção antes de compartilhar detalhes.

Inclua a versão, o sistema operacional e o comportamento observado. Use dados fictícios no exemplo e remova informações pessoais. Para erros comuns do editor ou da linguagem, use os [modelos de issue](https://github.com/alumia-brasil/alumia-br/issues/new/choose).
